🚀 How to Set Up Your Remote Desktop (Linux/VPS)

What you need: A Linux machine, VPS, or old computer with internet access. No cost required if you use what you already have.

Step 1: Install VNC Server

On your remote machine (Linux), run:

sudo apt update && sudo apt install tigervnc-standalone-server -y

Step 2: Start the VNC Server

Create a VNC session:

vncserver :1 -geometry 1920x1080 -depth 24 -passwd

This will prompt you to create a password. Remember it!

Step 3: Install WebSockify (Proxy)

WebSockify converts VNC to WebSocket so your browser can connect:

sudo apt install python3-pip -y && pip3 install websockify

Step 4: Start WebSockify

websockify 6080 localhost:5901 --web=/usr/share/novnc/ &

This listens on port 6080 and proxies to your VNC server at 5901.

Step 5: Open Firewall (if needed)

sudo ufw allow 6080/tcp

Step 6: Connect from Here

Find your machine's IP:

hostname -I

Then go to the Add VM tab and enter:

  • WebSocket URL: ws://YOUR_IP:6080/
  • VNC Password: The password you set in Step 2

Troubleshooting

  1. Connection refused? Check the VNC server is running: vncserver -list
  2. Port already in use? Use a different display number: vncserver :2
  3. Black screen? Your remote machine needs a desktop environment (XFCE, GNOME, etc.)
  4. Can't connect from outside network? You may need to port-forward 6080 on your router, or use a VPN.
✓ Ready! Once connected, you'll have full remote desktop access. You can then save multiple machines here and switch between them.

🍎 ChromeOS + Crostini Setup Guide

For ChromeOS users: If you have Crostini (Linux container) enabled, you can set up a local VNC server on your Chromebook. Another user on your device might have it—ask them to help!

Prerequisites

You need Crostini (Linux on ChromeOS) enabled on your Chromebook. This usually comes pre-installed on newer models.

  • Open the Terminal app on your Chromebook
  • If it opens a Linux terminal, you're good!
  • If you see an error, Crostini isn't set up—ask the other user to enable it
⚠️ Important: These commands must be run by the user who has Crostini enabled. If that's not you, have that user follow these steps and share the WebSocket URL with you.

Step 1: Install VNC Server (in Crostini Terminal)

The user with Crostini runs:

sudo apt update && sudo apt install tigervnc-standalone-server -y

Step 2: Start VNC Server

Still in the Crostini terminal:

vncserver :1 -geometry 1920x1080 -depth 24 -passwd

You'll be prompted to create a password. Write this down!

Step 3: Install WebSockify

sudo apt install python3-pip -y && pip3 install websockify

Step 4: Start WebSockify

websockify 6080 localhost:5901 --web=/usr/share/novnc/ &

The & at the end runs it in the background. Leave this terminal open.

Step 5: Get the IP Address

In the same terminal, type:

hostname -I

You'll see something like 127.0.0.1 or an IP like 192.168.1.100

Step 6: Add to This Launcher (Your Account)

Now switch to your user account and open this launcher. Go to the "Add VM" tab:

  • VM Name: Shared Crostini VM (or whatever you want)
  • OS: Linux
  • WebSocket URL: ws://localhost:6080/ (if same device) OR ws://[IP]:6080/ (replace [IP] with the number from Step 5)
  • VNC Password: The password from Step 2
  • RAM: 2 GB (or more if available)
  • Storage: N/A for Crostini
  • CPU: 2 (or more)

Click Save VM. Done! You can now connect whenever you want.

Keeping It Running

Important: The other user needs to keep their Crostini terminal open with WebSockify running. If they close it, the connection won't work.

To check if it's still running, they can type:

ps aux | grep websockify

Troubleshooting

  1. WebSocket URL not working? Make sure the Crostini terminal with WebSockify is still open
  2. Wrong password? The VNC server might need to be restarted: vncserver -kill :1 then run the start command again
  3. Black screen? Crostini might need a desktop environment. Try: sudo apt install xfce4 -y
  4. Permission denied? Add sudo before commands if you get errors
✓ All Set! You now have remote desktop access to the shared Crostini Linux environment. Go to "My VMs" and click Connect!
